# Текст Презентации Дипломного Проекта

### Вступление
Тема проекта: автоматическое распознавание автомобильных номерных знаков в реальном времени на RTSP-потоке.

Задача сложная по нескольким причинам: номера занимают малую долю кадра, часто сняты под углом, в кадре одновременно несколько машин, а компрессия RTSP дополнительно снижает качество изображения.

### Применение
Проект ориентирован на реальные сценарии: парковки, въездные группы, дорожные камеры, контроль транспортного потока.
Поддерживаемые входные источники: фото, видеофайл, RTSP-поток, веб-камера.

### Архитектура и методы
Гибридный подход: классический Computer Vision + Deep Learning.

Пайплайн:
1. Детекция номерной области — YOLO26n со sliced inference для кадров высокого разрешения.
2. Геометрическая коррекция — Harris corner detection + Homography выравнивание перспективы.
3. Восстановление качества кропа — Gray-world color balance, CLAHE, auto-gamma, Unsharp mask sharpening, Bilateral denoising.
4. Бинаризация — Otsu thresholding для подготовки к OCR.
5. OCR — CRNN + CTC Loss, читает номера переменной длины.
6. Стабилизация — KCF/CSRT трекинг между кадрами снижает дребезг детекций.
7. Постобработка — классификация цвета и формата плашки.

### Обучение моделей
Детектор YOLO26n: fine-tune на AUTO.RIA и объединённом датасете. Цель — надёжная детекция в wide-shot сценах высокого разрешения.

OCR CRNN+CTC: обучение на synthetic и real данных. Дополнительно — scene-specific fine-tune под конкретную RTSP-сцену.

### Результаты

Детектор (после fine-tune, epoch 5):
- Precision: 0.978
- Recall: 0.946
- mAP50: 0.985
- mAP50-95: 0.706

OCR:
- Synthetic validation: CER 0.036, exact match 83.5%
- Real validation: CER 0.237, exact match 47.79%

Реальный RTSP-поток (2592×1520, imgsz=1536, conf=0.25):
Система стабильно читает номера AA5104EK, KA1959BI, AA2162TX.
Повышение confidence-порога с 0.08 до 0.25 устранило ложные срабатывания без потери полезных детекций.

### Вывод
Только детектора или только OCR недостаточно для надёжного ALPR в реальной сцене.
Рабочий результат даёт связка: fine-tuned detector + геометрическое выравнивание + классическое восстановление качества + CRNN+CTC + scene-specific адаптация.

## Короткая версия (~3 минуты)

End-to-end ALPR система для RTSP-камеры: детекция номера, геометрическое выравнивание, восстановление качества кропа, OCR, классификация типа и цвета плашки.

Пайплайн: YOLO26n со sliced inference → Harris corner detection + Homography выравнивание → Gray-world color balance, CLAHE, auto-gamma, Unsharp mask, Bilateral denoising, Otsu thresholding → CRNN+CTC OCR → KCF/CSRT трекинг для стабилизации.

Обучил:
- YOLO26n на AUTO.RIA + объединённом датасете,
- CRNN+CTC на synthetic и real OCR данных,
- scene-specific OCR fine-tune под конкретную камеру.

Результаты:
- Детектор: Precision 0.978, Recall 0.946, mAP50 0.985, mAP50-95 0.706.
- OCR: synthetic exact match 83.5% (CER 0.036), real exact match 47.79% (CER 0.237).

На RTSP-потоке 2592×1520 (imgsz=1536, conf=0.25) система стабильно читает AA5104EK, KA1959BI, AA2162TX. Повышение conf с 0.08 до 0.25 устранило ложные срабатывания.

Вывод: надёжный ALPR требует комбинации fine-tuned detector + классическое восстановление качества + CRNN OCR + scene-specific адаптация.
