========================================
Dataset: AUTO.RIA Ukrainian License Plates (autoriaNumberplateDataset)
- Training samples: ~3200 (from full dataset)
- Validation samples: ~800
- Classes: 1 (license_plate)
- Image resolution: 640×640 (training), 1536×1536 (inference for better small-plate recall)
- Annotations: COCO format → YOLO format

Training Config:
- Model: YOLOv8 nano (yolo26n.pt as baseline)
- Epochs: 30
- Batch size: 16 (GPU: RTX/V100)
- Learning rate: 0.001 (default schedule)
- Augmentation: Mosaic, rotation, scale, flip, color jitter (YOLOv8 defaults)
- Optimizer: SGD with momentum

Key Metrics (Final, Epoch 30):
- Precision: 97.42%
- Recall: 93.01%
- mAP50: 97.79%
- mAP50-95: 67.77%
- Training time: ~11 hours
- Inference time (1 image 1536×1536): ~85ms (GPU)

Results:
✓ High precision minimizes false positives (important for parking scenes)
✓ Recall ~93% catches most visible plates
✓ mAP50 > 97% indicates robust detection even under challenging angles/lighting
✗ mAP50-95 lower due to difficulty with small/distant plates (expected for this task)

PHASE 2: CRNN+CTC OCR Training
===============================
Dataset: Synthetic + Real (Zenodo, OCR crops, scene captures)
- Synthetic training: ~18,000 (generated with randaugment on UA plate templates)
- Real validation: ~136 samples (manual collection from IP camera)
- Synthetic validation: ~2,000 samples
- Alphabet: Digits + Latin + Ukrainian Cyrillic + special chars (68 classes + CTC blank)
- Input: 32×W grayscale (width variable, height normalized)

Architecture:
- CNN backbone: 5 conv-blocks (conv→BN→ReLU + MaxPool)
- RNN: BiLSTM×2 (256 hidden units each)
- Decoder: CTC (Connectionist Temporal Classification)
- Total params: ~2.1M

Training Config:
- Epochs: 20
- Batch size: 64
- Learning rate: 3e-4 (Adam optimizer)
- Loss: CTC loss (supports variable-length sequences)
- Training time: ~4 hours

PHASE 4: Preprocessing Pipeline (ДЗ2-8 CV Techniques)
======================================================
Applied to each plate crop before OCR:
1. Color balance (Gray-world from ДЗ2)
2. CLAHE histogram equalization (lesson_2)
3. Auto-gamma correction (lesson_2)
4. Unsharp mask sharpening (ДЗ3)
5. Rectification via Harris corners + homography (ДЗ6-7)
6. Optional Otsu binarization (ДЗ8)

Effect: +15-20% OCR accuracy on degraded crops (test set)

---

PHASE 5: Tracking & Temporal Filtering (ДЗ10)
==============================================
Trackers: KCF, CSRT (via cv2.legacy.TrackerKCF, cv2.TrackerCSRT)
Purpose: Smooth predictions across frames, reduce flicker, improve robustness
- Consensus voting: majority text match across 4+ frames
- Confidence smoothing: temporal moving average
- Results: Reduces false positives, stabilizes OCR output in video

---

REAL-WORLD DEPLOYMENT
======================
RTSP Stream Test (2592×1520 @ 50 fps):
- Stable detection of 3-5 vehicles per frame (parking lot scenario)
- Effective FPS: 0.85 FPS (due to high resolution; optimizable with slicing)
- Standard white plates: 95%+ detection+OCR accuracy
- Blue plates: 80%+ accuracy
- Distant/angled plates: 60-70% accuracy (acceptable for parking)

Known Limitations:
- Named/vanity plates: Lower OCR confidence (mixed format)
- Small/distant plates: Requires higher imgsz (1920+) and longer inference
- Heavy compression (RTSP H.264): Degrades OCR (mitigated by preprocessing)
- Tilted angles >45°: Lower homography quality

---

RECOMMENDATIONS FOR PRODUCTION
===============================
1. Increase imgsz to 1920 for better small-plate recall (trade-off: slower)
2. Fine-tune on real parking/street data (transfer learning from current weights)
3. Implement plate color classification (diplomatic/taxi/special detection)
4. Add multi-model ensemble (YOLO + Faster-RCNN) for robustness
5. Deploy with tracking to reduce temporal noise
6. Cache CRNN weights on GPU for real-time performance (current: 85ms/image)
